# 💱 Python Currency Converter

A simple terminal-based currency converter written in Python using the Frankfurter Exchange Rate API.

## Features

- 🌍 Live exchange rates
- 💱 Convert between currencies
- ✅ Check if a currency is supported
- ⚠️ Handles invalid currency codes
- 🔢 Handles invalid amount input
- 🌐 Connection error handling
- ⏱️ Request timeout handling
- 🖥️ Simple terminal interface

## Technologies

- Python
- Requests
- Frankfurter API

```text

2. Convert Currency
